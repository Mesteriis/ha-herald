# Flows

Built-in flows:

- `security_alerts`
- `system_events`
- `device_alerts`
- `ai_events`
- `energy_events`
- `camera_alerts`
- `timer_notifications`

Each flow supports:

- `enabled`
- `severity`
- `channels`
- `conditions`
- `personality`
- `summary_personality`
- `allow_summary`
- `summary_window_seconds`
- `dedup_window_seconds`
- `cooldown_seconds`
